# ISRC 每日签到（Chrome 扩展）

## 安装

1. 将 ZIP 解压到一个固定位置，保留整个 `isrc-llmapi-auto-checkin` 文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `isrc-llmapi-auto-checkin` 文件夹。
4. 使用已经登录 llmapi.isrc.ac.cn 的同一 Chrome 配置文件。安装完成会自动尝试签到。
5. 在工具栏打开本扩展，查看结果；也可以点击“立即检查”。建议固定到工具栏。

Chrome 不支持直接将这个 ZIP 当商店扩展安装。文件夹加载后请不要移动或删除。

## 行为

- 安装、浏览器启动、北京时间跨日后后台执行。不会自动打开网页。
- 弹窗显示当前总余额，打开时自动查询，也可点击“刷新余额”；手动签到检查后会刷新余额。显示更新时间，查询失败时显示原因，不继续展示旧账号的余额。
- 余额读取 `/api/user/self` 的 `quota`，根据 `/api/status` 的单位配置显示；配置不可用时明确显示原始额度单位。
- 每分钟的本地闹钟只检查是否需要执行；签到成功后当天不再自动请求签到；打开弹窗查询余额仍会访问网站。
- 浏览器关闭或电脑休眠时不执行，恢复后补做，不补签历史日期。
- 成功、当天已签到、失败均给出系统通知，工具栏也显示 ✓ 或 !。
- 网络错误、限流、服务器故障首次失败后最多重试三次，间隔约 1、5、30 分钟。首次和最终失败通知，避免每次重试都打扰。
- 登录失效、安全验证、拒绝访问等停止当天自动重试。在网站登录或处理验证后，点击“立即检查”。
- 只有主动点击“打开网站 / 登录”才会创建网页标签。
- 奖励显示接口返回的原始额度单位，不擅自换算成人民币、美元或 token。
- 自动执行以当前浏览器配置文件当天成功记录去重。同一天切换网站账号后，请手动点击“立即检查”。
- “关闭自动签到”停止后续自动执行，已发出的请求可能仍会完成；仍可手动检查。

## 登录与权限

仅允许访问 https://llmapi.isrc.ac.cn/，使用浏览器现有 Cookie 请求刷新接口，再用返回的短期令牌签到。不读取密码，不导出 Cookie，不持久保存令牌，不发送数据到第三方。短期令牌仅保留在当次任务的内存中。

权限：alarms（定时检查）、storage（状态）、notifications（桌面通知）及目标站点 host_permissions。没有浏览历史、全部网站、调试器或 Cookie 读取权限。

网站若限制跨扩展请求、浏览器阻止登录 Cookie、登录过期或启用验证码，后台流程可能无法完成。扩展会展示错误原因，不能绕过验证。若没有系统通知，请查看 Chrome/桌面环境通知设置；扩展弹窗仍保留结果。

## 已核对和测试

2026-10-18 根据网站公开前端代码核对：

- POST /api/user/auth/refresh：使用登录 Cookie 获取 access_token。
- GET /api/user/checkin?month=YYYY-MM：查询 stats.checked_in_today。
- POST /api/user/checkin：签到，读取 quota_awarded。

通过 12 项模拟测试：北京时间跨日、认证与签到请求、已签到去重、登录过期、超时后的结果核对、验证码、服务器故障、响应格式变化，以及 worker 并发去重/通知失败/重试上限/暂停；新增余额单位换算、零余额、账号一致性和配置读取失败回退测试。

当前工具无法连接用户的 Chrome，尚未在真实登录会话中验证 Cookie 与服务器跨域策略，也未实际加载扩展进行浏览器端测试。安装后请先确认弹窗结果。接口变动时可能需要更新扩展。

## 从源码安装与测试

克隆本仓库后，在 Chrome 扩展管理页直接加载仓库目录。测试不需要额外依赖：安装 Node.js 22 或更新版本，运行 `npm test`。
